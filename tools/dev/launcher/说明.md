# 龙娘pcr.exe 是怎么来的

V1.0 起，项目文件夹最外层的 `龙娘pcr.exe` 是用这里的源代码编译出来的小程序，随每个版本一起发。
更早的测试版用的是 `启动.bat` 加上每台电脑现做的 exe，现在都没有了，它们干的事全在这个 exe 里。

## 它做什么

| 怎么启动 | 做什么 |
| --- | --- |
| 双击，运行环境在 | 用 `pythonw tools\menu.py window` 打开界面，自己退出。没有黑窗口 |
| 双击，运行环境不在（第一次） | 开一个黑窗口显示进度：下载 uv → `uv venv --python 3.12` → `python tools\menu.py prepare`（装依赖）→ 打开界面，黑窗口关掉 |
| `龙娘pcr.exe clear / farm / scan / setup / export / update / console` | 开一个黑窗口，参数原样交给 `tools\menu.py` |
| `龙娘pcr.exe --setup` | 内部用：界面发现依赖不全时叫它来装（`menu.run_window`） |

- 运行环境的位置、环境变量和原来 `启动.bat` 里的一模一样（`%LOCALAPPDATA%\longniang-pcr`），多一个 `LNPCR_EXE`（exe 自己在哪）。
- uv 只从 `github.com/astral-sh/uv` 的发布页下载（和原来 `启动.bat` 里是同一个地址）。下载走环境变量里的代理；没设就读 Windows 设置里的
  「代理服务器」（注册表 `Internet Settings` 的 `ProxyEnable` / `ProxyServer` 两项，只读）；都没有就直连。失败重试 3 次，60 秒没动静算断。
- uv 走不通：用电脑上已经装好的 Python（先 `py -3`，再 `python`，要 3.10 ~ 3.13）建环境。都不行：说明原因，等回车。
- 只用 Go 的标准库；Windows 的东西只碰 kernel32 / user32（开窗口、弹框）和注册表那两项。不读不改游戏、模拟器。

## 文件

- `core.go`：路径、环境变量、整个流程（`flow`、`bootstrap`）——和操作系统打交道的事都从 `ops` 里拿，所以能用假的来测。
- `fetch.go`：代理、下载、解压。
- `main.go`、`host_windows.go`：真的那一套（开窗口、弹框、启动程序、读代理设置）。`host_other.go`：别的系统上的替身，只为了能跑自测。
- `launcher_test.go`：自测（流程 8 条路 + 代理 + 下载（本机起一个假服务器：跳转、出错重试、给一半、卡住）+ 解压）。
- `launcher.rc`、`launcher.ico`、`rsrc_windows_amd64.syso`：图标（logo）和版本信息。`make_ico.py`：用 `assets/logo.png` 做图标。
- `build.sh`：做 exe。

## 重新做

要装 Go（1.21 以上），不用联网。在这个文件夹里：

```
go test ./...
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags "-H windowsgui" -o ../../../龙娘pcr.exe .
```

（Windows 的命令行里：先 `set GOOS=windows`、`set GOARCH=amd64`、`set CGO_ENABLED=0`，再运行后半句。）
同一份源代码、同一个 Go 版本（现在这个是 go1.24.7 做的）做出来的 exe 一个字节都不差——`tests/test_gui.py::test_exe_is_the_compiled_launcher` 就是这么核对
“发出去的 exe 是不是这份源代码做的”。所以**改了这里的任何一个 .go 文件，都要重新做 exe**，不然那条自测会报。
图标 / 版本号改了：`./build.sh res`（要 Python + Pillow、llvm-rc、llvm-cvtres）。

## 自测管不到的地方

- 做 exe 的环境是 Linux，流程自测是用同一份代码在 Linux 上跑的（假的运行环境、假的下载服务器）。开黑窗口、弹框、读注册表里的代理
  这几样只有在 Windows 上才走得到，没有自动测试盖着，改这几处以后要在 Windows 上亲手试一遍：平时双击打开界面、
  删掉 `%LOCALAPPDATA%\longniang-pcr` 以后第一次准备环境、命令行里带参数运行。
- 没有数字签名：从网上下载以后第一次运行，Windows 会弹「已保护你的电脑」，要点「更多信息 → 仍要运行」；个别杀毒软件可能误报
  （Go 编译的、会联网下载的小程序比较容易被这样对待）。
