# 龙娘pcr

《公主连结》国服「黎明界迷宫（难度 5）」自动化工具。本工具运行在 MuMu 模拟器上，仅通过识别屏幕画面和模拟触摸来完成走图、编队、战斗、选择角色与遗物、商店购买等操作。

> **目前仅支持 MuMu 模拟器**（Windows 版网易 MuMu 模拟器，分辨率 1920×1080）。暂不支持雷电、夜神、蓝叠等其他模拟器，也不支持真机。

当前版本：**V1.02**（正式版）。交流 QQ 群：**891856490**。

## 使用须知

- **支持范围**：目前仅支持 MuMu 模拟器和《公主连结》国服。模拟器的查找、截图与点击均按 MuMu 实现，其他模拟器未做适配，也未经测试。
- **工作方式**：仅识别屏幕画面并模拟触摸操作，不修改客户端、不读取内存、不抓包、不直接调用游戏服务器接口。
- **操作范围**：仅在黎明界迷宫相关页面内操作（以及必要的启动、返回流程），不涉及抽卡、宝石和付费商店。遇到无法识别的画面时会停止操作；验证码和任何付费确认均交由使用者处理。
- **门票**（游戏内称「通行证」）：击败最终首领后，游戏会自动结算并消耗 1 张门票。只有在当次运行前亲自勾选「使用门票」，本工具才会挑战最终首领；该选项每次都需要重新勾选，开始前还会再次确认。
- **风险提示**：使用自动化脚本违反游戏用户协议，存在被处罚的风险，该风险由使用者自行承担。
- **运行记录**：每次运行都会保存日志和截图（`logs/runs`），可在事后查看每一步操作。
- **联网行为**：本工具平时不联网。只有以下三项操作会联网，且均由使用者主动触发：首次准备运行环境（GitHub、PyPI）、「扫描角色」（读取资料站 pcr.satroki.tech、redive.estertion.win）、「检查更新」（GitHub）。

## 环境要求

- 64 位 Windows（本工具在 Windows 11 上开发和测试）。
- MuMu 模拟器，分辨率设置为 1920×1080，并已安装《公主连结》国服。
- 首次运行需要联网（访问 GitHub 和 PyPI），运行环境约占用 500 MB 磁盘空间。

## 安装与首次使用

1. **准备模拟器**：安装 MuMu 模拟器，将分辨率设置为 1920×1080，并安装游戏。
2. **下载并运行**：在 [Releases](https://github.com/bwxnQAQ/longniang-pcr/releases) 页面下载最新版本的「Source code (zip)」，将压缩包完整解压后，双击其中的 `龙娘pcr.exe`（请勿在压缩包内直接运行）。
   - 首次运行时会打开一个命令行窗口来准备运行环境（需要联网，约占用 500 MB，耗时数分钟）。准备完成后该窗口自动关闭，并打开主界面；此后再次运行将直接打开主界面。
   - Windows 可能提示「Windows 已保护你的电脑」，原因是本程序没有数字签名。点击「更多信息」→「仍要运行」即可继续。
   - 准备运行环境需要访问 GitHub 和 PyPI。无法访问时，可开启代理后重新运行（程序会使用 Windows 系统设置中的代理），或自行安装 Python 3.12 后重新运行。
3. **首次设置**：主界面顶部会显示「首次设置」一栏（仅首次使用时出现）。点击「开始首次设置」后，工具会依次检查运行环境、模拟器以及挂机所需的各项条件（不操作游戏，约需一分钟），未通过的项目会给出处理方法。最后会询问是否扫描角色，扫描前需先将游戏停留在主界面底部的「角色」页。完成后该栏不再显示。

## 功能说明

### 主界面

主界面是一个小窗口：各栏均收起时，窗口恰好容纳全部内容，无需滚动；展开某一栏后，内容超出窗口时可滚动查看。关闭窗口即退出本工具（正在执行的任务会先停止）。窗口顶部显示版本号，底部始终显示 QQ 群号。

状态栏显示当前正在执行的操作。右侧的「停止」按钮与 **F12** 键作用相同：在下一个动作之前停止。点击「输出 ▸」可查看逐步的执行记录，再次点击返回。工具需要使用者确认时，会出现一条蓝色的询问栏，点击相应按钮即可回答。

### 黎明界迷宫

- **档位**（四选一）
  - 1 最高凹分：极难关卡全部挑战；无法到达极难关卡、首领不符合要求、前两个区域的事件收益偏低、第二层无法绕开商店时，均撤退重开。
  - 2 极难全打：极难关卡全部挑战，仅在无法到达极难关卡时重开。
  - 3 稳着打：能到达的极难关卡都挑战，无法到达时不重开；战斗失败时多一次重打机会。
  - 4 保通关：尽量不走极难关卡；极难关卡和首领战首次挑战即编入坦克和治疗角色。
- **公会**：十个公会均可选择。默认为「刷分」，即由工具自行选择：初期使用咲恋救济院，待各公会均积累数局成绩后，改为选择平均估分最高的公会。
- **使用门票**：对应界面上的「使用门票（不勾选则停在最终boss前）」选项。
  - 不勾选：仅进行一局。走完五个区域、到达最终首领前即停止，任务结束。此时不撤退、不挑战最终首领、不消耗门票，并给出击败最终首领可获得的估分。之后由使用者自行决定：手动击败最终首领即可结算；不需要这一局时，在地图上手动点击「撤退（无报酬）」。按档位规则需要重开的情况（例如无法到达极难关卡、战斗失败）仍会照常撤退重开，不计为完成。
  - 勾选：到达最终首领后继续挑战并结算，每成功完成一局消耗 1 张门票。
    - 「打几局」：成功完成（击败最终首领并结算）才计为一局，达到设定局数后停止。
    - 「到多少分才结算」（0 = 不看分数）：填写分数（例如 50000）后，到达最终首领前会先估算分数，未达到的对局撤退重打，不消耗门票、不计入局数。连续 30 局未达到分数时会停止（`walk.settle_max_tries`），以免分数线设置过高导致一直重打。
    - 未能击败最终首领时同样撤退重打，不消耗门票、不计入局数。
    - 未勾选时，「打几局」和分数两项为灰色，不生效。
- **更多选项**（各选项默认均不勾选，按需勾选；勾选状态会被记住）
  - 「每场打完看伤害报告」：战斗结束后查看每名角色的伤害，用于调整输出角色的权重，并在战斗失败后更换角色。
  - 「编完队自动装备特别装备」：编队完成后点击「特别装备」→「自动装备」。已自行配好装备、不希望被更换时请勿勾选。
  - 「换日 / 掉线后自己走回迷宫」：用于长时间挂机。不勾选时，遇到换日或掉线即停止。
  - 第一档专用的选项：仅保留或遇到即重开的首领（填写名称）、第二层无法绕开商店时重开。
  - 定时开始，以及指定时间之后不再开始新的一局。

### 按饰品数量连续刷

选择需要的饰品（可具体到某一件、某个系列、某个部位或某种属性）后，工具会自行选择能够产出该饰品的公会，逐局通关、开启宝箱并记录战利品，达到目标数量后停止。每通关一局消耗 1 张门票；未勾选「使用门票」时，工具只给出说明，不执行任何操作。

目标通过「按分类加」添加：选择属性、部位 / 系列和数量后，点击「加进目标」。已添加的目标以标签形式显示，点击 ✕ 可移除单个目标，点击「清空」可移除全部目标。未添加任何目标时点击「开始连续刷」不会开始，并会提示先添加目标。

### 统计

展开后可查看两项内容：

- **各公会的成绩**：完成的局数、平均估分、最高分。
- **运行记录**：每次运行保留一条，按时间倒序排列；整个列表可收起，每条记录可单独展开或收起。

### 其他

- **扫描角色**：获得新角色或游戏更新了新角色后使用。工具先在游戏的「角色」页读取已拥有的角色（仅点击第一张角色卡和右侧的 ▶），再从资料站（pcr.satroki.tech）更新角色名单、属性和头像。编队时依靠这些数据识别角色。使用前需先将游戏停留在主界面底部的「角色」页。
- **导出排查包**：出现问题时使用。工具会将最近几次运行的记录、关键截图、设置和环境信息打包为一个 zip 文件（位于项目文件夹的「排查包」目录）。请将该文件发送到 QQ 群 891856490，并说明当时正在执行的操作和出现的问题。请注意：排查包内含游戏截图（可见角色和玩家名称）以及项目文件夹的路径。
- **检查更新**：访问 GitHub 检查是否有新版本（依据仓库的版本标签）。发现新版本时会先询问，确认后下载并替换，随后主界面自动重新打开。
  - 仅替换程序本身（`龙娘pcr.exe`、`longniang_pcr`、`tools`、`assets`、`data` 中随版本发布的文件，以及本说明）。使用者的数据不受影响：`config/settings.json`、`data/learned`、`logs`、`排查包`。
  - 替换前会完整检查新版本的文件，检查不通过则不替换；替换中途出错会自动恢复原状。被替换的旧文件保存在 `%LOCALAPPDATA%\longniang-pcr\backup`（保留最近 3 次），需要回退时将其中的文件复制回原位置即可。
  - 仅连接 GitHub，且仅访问本仓库。无法连接时，可开启代理后重试（程序会使用 Windows 系统设置中的代理）。
  - 各版本的更新内容见 `CHANGELOG.md`。
- **重置到初始状态**：将本工具恢复到刚下载时的状态。
  - 清除：`logs`（运行记录和截图）、`data/learned`（学习到的数据，包括已拥有的角色）、`排查包`、界面记住的选项、检查更新时保留的旧文件；`config/settings.json` 恢复为默认内容。
  - 保留：程序本身和 Python 运行环境（无需重新下载）。
  - 清除前会列出将要清除的内容并再次确认。**清除后无法恢复。** 完成后主界面自动重新打开，「首次设置」会重新出现。

## 自动停止的情况

出现以下情况时，本工具会自动停止：

- 画面连续 20 秒以上无法识别；
- 出现流程中未预料到的页面；
- 多次点击后画面没有变化；
- 门票数量与预期不符；
- 战斗失败且重打次数用尽（此时会撤退重开）；
- 点击次数或运行时间达到上限；
- 使用者按下 F12 或点击「停止」。

停止时触摸已经释放，游戏停留在当前画面。如果当前对局仍在进行中而使用者不需要这一局，可在地图上手动点击「撤退（无报酬）」，门票不会减少。

自动运行期间，如果使用者手动操作模拟器，工具会暂停并等待；手动操作结束后自动继续。

## 文件与目录

- `logs/runs/<时间>_<名称>/`：每次运行的记录，包括 `log.txt`（逐步的详细日志，比界面上的「输出」更详细）、`events.jsonl` 和 `shots/`（截图）。
- `config/settings.json`：设置文件。常用项：`stop_key`（紧急停止键，默认 F12）、`notify`（运行结束后弹出通知）、`detail_output`（在界面的「输出」中显示点击坐标等细节）、`farm.keep_passes`（门票数量不多于该值时不再使用）。
- `data/learned/`：工具学习到的数据，包括头像库、获胜过的队伍、各角色的伤害记录和战利品账本。删除后不影响使用，但需要重新学习。
- `排查包/`：导出的排查包。
- `%LOCALAPPDATA%\longniang-pcr`：Python 运行环境和依赖。删除后再次运行 `龙娘pcr.exe` 会重新准备。界面上次选择的档位、公会等选项也保存在此处（`gui_prefs.json`）。

## 命令行

一般无需使用。在本文件夹内打开命令行后可执行：

| 命令 | 作用 |
| --- | --- |
| `龙娘pcr.exe clear` | 黎明界迷宫 |
| `龙娘pcr.exe farm` | 按饰品数量连续刷 |
| `龙娘pcr.exe scan` | 扫描角色 |
| `龙娘pcr.exe setup` | 重新进行首次设置 |
| `龙娘pcr.exe export` | 导出排查包 |
| `龙娘pcr.exe update` | 检查更新（`update --check` 仅检查，不替换） |
| `龙娘pcr.exe reset` | 重置到初始状态 |
| `龙娘pcr.exe console` | 打开命令行菜单 |

## 更新记录

最新的版本排在最前面。通过「检查更新」可以更新到最新版本。

### V1.02（2026-11-26）

- 修复：使用拉比林斯开局时，开局角色加入后弹出的「迷宫遗物效果」对话框无法识别，导致停止。现在会识别该对话框并点击「关闭」。
- 修复：咲恋救济院的商店有折扣，原先按平常价格设定的购买标准在该公会下判断不准（例如把 ★2 遗物当作便宜货购买）。现在会先算出折扣，再按平常价格的标准判断，预留金币按折后价格计算。
- 修复：金币不多时，可能在更新商品后买不起 ★1 遗物的情况下仍然花金币更新。现在只有更新后买得起一个 ★1 遗物才更新，否则直接购买货架上的印记。
- 修复：运行中手动点击模拟器后，工具可能沿用点击前的编队计划，提示“队伍编组里一个能上场的角色都没有”并停止。现在手动操作结束后会重新读取名单、重新编队；名单暂时读不到时会多看两次再判断。
- 改进：导出排查包时，优先装入停止时保存的截图（此前截图较多时，这些截图可能因超出大小上限而未被装入）。

### V1.01（2026-11-25）

- 修复：电脑上存在多个 MuMu 安装时，可能选中未在运行的那一个，导致提示“ADB 连不上模拟器”。现在会依次查询各个安装，使用正在运行的那一个。
- 改进：无法从 MuMu 的命令行工具获取 ADB 端口时，先读取 MuMu 配置文件中登记的端口，再尝试多开实例常用的端口。
